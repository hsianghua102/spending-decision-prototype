# 日常｜消費決策助手 Prototype

Mobile-first 的可操作消費決策原型。它從真實記帳情境開始，在使用者產生具體消費需求、且看見既有資料分析完成後，才說明並詢問薪資資料授權。

## 執行

這是零依賴靜態前端，可直接開啟 `index.html`，或使用：

```bash
python3 -m http.server 8000
```

開啟 <http://localhost:8000>。

## Prototype flow

1. 記帳首頁：財務摘要與情境式入口
2. 建立決策：商品、金額、想要／需要
3. 資料分析：顯示既有資料價值與收入缺口
4. 授權說明：交代讀取範圍、用途與限制
5. 模擬銀行授權：銀行選擇、Loading、Success
6. 決策模擬：付清、分三期、延後購買的互動比較

所有資料皆為 Mock Data，只存在頁面 local state，不連接銀行、後端或外部 API。
